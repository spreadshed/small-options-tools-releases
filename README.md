# SpreadShed small options tools

Free, small tools for options traders by [@TheSpreadShed](https://x.com/TheSpreadShed), built with Claude Code.

Every tool answers one question, runs without accounts or servers, and uses only the numbers you type in from your broker. Educational tools, not financial advice.

## Opening a spreadsheet

- **Excel:** open the `.xlsx` file.
- **Google Sheets:** in Google Drive, choose **New → File upload**, then open the file with Google Sheets.
- **LibreOffice Calc:** open the `.xlsx` file.

The spreadsheets use formulas only: no macros, no add-ons, no internet connection. Your trades stay in your own file.

## Tool 1: Covered Call Evaluator & Log

Checks a covered call before you sell it, then logs every leg and adds up your profit and loss.

- **Evaluator:** two verdicts, assignment risk (PASS / WARN / FAIL) and trade quality (GO / CAUTION / NO-GO)
- **Trade Log:** one row per leg, with automatic position IDs, P/L and status
- **Summary:** total, realized and open P/L, win rate and activity
- **Example:** a filled-in log with two made-up trades
